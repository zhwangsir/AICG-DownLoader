# AI 短剧工作台 — 用户手册

## 1. 概述

AI 短剧工作台是一个从"一句话创意"到"可播放短剧成片"的一站式生产工具。通过 9 个 Agent 的协作，自动生成剧本、角色定妆照、分镜、视频片段、配音、字幕、成片，并提供文本质检和视觉质检。

## 2. 启动与界面

### 2.1 启动服务

1. 启动后端：`cd platform/backend && uv run uvicorn app.main:app --reload --port 8100`
2. 启动前端：`cd platform/frontend && npm run dev`
3. 浏览器访问：`http://localhost:5173`

### 2.2 主界面

- **顶部工具栏**：按从左到右的工作流顺序排列操作按钮
- **画布区域**：显示当前项目的节点图，节点包括剧本、角色、分镜、视频、配音、字幕、成片、质检
- **左侧节点面板**：展示各类节点的图例
- **底部状态栏**：显示当前操作状态和基础设施连接情况

## 3. 标准工作流

### 3.1 生成剧本

1. 点击右上角「生成剧本」
2. 输入一句话创意、题材、集数、每集分镜数
3. 点击「生成」，等待 3-5 分钟
4. 画布将出现「剧本」节点

### 3.2 生成角色定妆照

1. 点击「生成角色」
2. 选择角色、画风、一致性层级
3. 点击「生成定妆照」
4. 每个角色会生成三视图并显示在角色节点中

### 3.3 生成分镜关键帧

1. 点击「生成分镜」
2. 选择场景和画风
3. 点击「生成分镜」
4. 分镜节点将嵌入生成的关键帧图片

### 3.4 生成视频片段

1. 点击「生成视频」
2. 选择已生成的分镜，设置视频时长
3. 点击「生成」
4. 通过 SSE 进度条查看生成进度，约 5-10 分钟
5. 视频节点将嵌入可播放的 MP4

### 3.5 生成配音

1. 点击「生成配音」
2. 选择场景，系统将自动为台词分配角色语音
3. 点击「生成配音」
4. 配音节点将嵌入音频播放器

### 3.6 生成字幕

1. 点击「生成字幕」
2. 选择已生成的配音
3. 点击「生成字幕」
4. 字幕节点将显示字幕文本预览

### 3.7 合成成片

1. 确保已生成至少一个场景的视频、配音、字幕
2. 点击「合成成片」
3. 设置成片标题、转场、分辨率、帧率
4. 点击「合成」
5. 成片节点将嵌入最终 MP4 播放器

### 3.8 质检

- **文本质检**：点击「质检」，检查剧本和字幕的台词一致性、剧情逻辑、敏感词
- **视觉质检**：点击「视觉质检」，选择视频片段，检查角色一致性、画面连贯性、异常画面（需 Qwen3-VL 部署，未部署时返回降级提示）

## 4. 注意事项

- 视频生成耗时较长（5-10 分钟/片段），请通过进度条耐心等待
- 视觉质检需要提前部署 Qwen3-VL 并配置 `VISUAL_MODEL_URL`
- 所有生成的静态资源可通过 `/static/*` 路径访问
